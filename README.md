## About Me

I'm a fourth-year Software Engineering student at Muğla Sıtkı Koçman University.

I develop computer-vision and machine-learning projects focused on real-time video processing, object detection, tracking, and privacy-preserving image analysis.

My current work includes practical vision systems, model benchmarking, and deployment-oriented development on Azure Linux. I also build mobile and web applications using Flutter, Dart, React, and Firebase.

### [Privacy Vision AI](https://github.com/ranayalcnn/privacy-vision-ai)

A KVKK-aware, real-time computer-vision platform designed for secure and privacy-conscious image and video analysis.

* Face anonymization using blur, mosaic, and color-mask modes
* Person blurring and removal with segmentation
* Multi-person pose estimation and tracking
