##  Hi, I'm Rana

I'm a fourth-year Software Engineering student at Muğla Sıtkı Koçman University, passionate about building intelligent, meaningful, and user-focused software.

My main interests are **computer vision**, **machine learning**, and **real-time AI systems**. I work on detection, tracking, video processing, and privacy-preserving image analysis.

Currently, I'm exploring practical vision systems, model benchmarking, and deployment-oriented development on Azure Linux. I also enjoy creating modern mobile and web applications with Flutter, Dart, and React.

> Creating software where intelligence meets thoughtful design. ✨

##  Featured Project

### [Privacy Vision AI](https://github.com/ranayalcnn/privacy-vision-ai)

A KVKK-aware, real-time computer-vision platform designed for safer and privacy-conscious image and video analysis.

* Face anonymization with blur, mosaic, and color-mask modes
* Person blurring and removal using segmentation
* Multi-person pose estimation and tracking
* Warehouse analysis for forklift, person, and pallet detection
* FastAPI web API and live-camera support
* Demo videos, performance tests, and security controls
